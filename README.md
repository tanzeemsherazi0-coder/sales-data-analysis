# Sales Data Analysis using Python

## Project Overview

This project analyzes sales data using Python to understand sales performance, product performance, and sales trends.

The analysis was performed on a sales dataset containing 200 records.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Excel

## Data Analysis

The following analysis was performed:

- Data loading and cleaning
- Total sales analysis
- Product-wise sales analysis
- Category-wise sales analysis
- Monthly sales analysis
- Daily sales trend analysis
- Best-selling products analysis
- Quantity sold by product
- Category-wise sales contribution
- Data visualization using charts

## Key Insights

- Electronics was the highest-performing category.
- Laptop was the best-selling product by sales value.
- February 2025 had the highest monthly sales.
- July 2025 had the lowest monthly sales.
- Keyboard and Mouse were among the products with the highest quantities sold.
- Sales varied across different months and days.

## Conclusion

This project helped me understand how Python can be used to analyze sales data and find useful business insights.

The analysis can help businesses understand their best-performing products, categories, and sales periods.

## Recommendations

- Focus more on high-selling products.
- Improve sales during low-performing months.
- Promote weaker categories to increase their contribution.
- Monitor products with high demand and maintain sufficient stock.
- Analyze sales regularly to support better business decisions.
